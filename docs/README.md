# Project Documentation

This directory is the source of truth for the Social Media Downloader project.
The product is designed as a compliant creator media vault for media a user owns
or is authorized to use.

## Document rules

- Update `PROJECT_STATE.md` whenever a milestone, blocker, or material decision changes.
- Record durable technical or product decisions as ADRs.
- Use **Proposed**, **Accepted**, **Deprecated**, or **Superseded** for decision status.
- Do not describe planned functionality as already implemented.
- Keep legal and platform-policy claims linked to primary sources.
- Review architecture, security, and API documents before every major release.

## Current phase

The project is in **Phase 0: product and compliance discovery**. No application
source code, backend service, or production infrastructure is present yet.
