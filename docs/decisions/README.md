# Architecture Decision Records

Architecture Decision Records document durable choices and their consequences.

## Status values

- **Proposed:** Under discussion.
- **Accepted:** Current direction.
- **Deprecated:** No longer preferred but may still exist.
- **Superseded:** Replaced by a newer ADR.

## Creating an ADR

Copy this structure into the next numbered file:

```md
# ADR NNNN: Decision title

**Status:** Proposed  
**Date:** YYYY-MM-DD

## Context

## Decision

## Consequences

## Alternatives considered
```
